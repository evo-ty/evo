Workspace / Guide

Build, launch, operate.

A short path through the EVO HUB workflow: create a Python server, manage its files, use Terminal for development commands, then start the live process from the control room.

Start a server

Set up your first isolated Python workspace in a few focused steps.

01
Create the workspaceOpen Create Server, choose a plan, name the instance and select Python.
02
Prepare your entry fileKeep your startup file as main.py, or select another file during setup.
03
Press STARTOpen the server management view and watch the live output in the Console.

Use Terminal

The Terminal is your command line for the selected server workspace.

01
Choose the targetOpen Terminal from the sidebar and select the server you want to work on.
02
Install and inspectUse commands such as ls, python --version, pip install and cat requirements.txt.
03
Keep it scopedCommands run inside the server folder. Each server also gets a public route such as server/09156854. Use the server controls for long-running services.

Manage files

Keep the project source and assets organized in one file workspace.

01
Upload or drag and dropUse My Files for Python files, ZIP archives, requirements.txt and assets.
02
Edit safelyOpen a text file in the editor, save changes, rename items or download a copy.

Monitor health

Keep the service visible after launch.

01
Read the ConsoleStartup output and application errors appear below the live server controls.
02
Check resourcesReview CPU, memory and disk cards before a small issue becomes downtime.
